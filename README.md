# 阅读

面向 Android、macOS 与 iOS 的本地电子书阅读器。阅读页只保留正文和进度；设置首页按字体、背景、翻页、界面、文件同步、密码和关于分类；各阅读样式子页共用一个完整预览。

## 功能

- TXT（UTF-8、UTF-16 BOM、GBK）、EPUB、MOBI / AZW / AZW3、HTML 可重排文字阅读。
- 本地书架、书名/作者搜索、排序、导入去重、阅读进度、目录、书签和全文搜索。
- 十种翻页动画及无动画选项，支持细粒子消散、原位水墨消散与粒子方向感开关、单页进度预览；支持触屏、方向键、空格、Page Up / Down、滚轮。
- 八套内置阅读配色、多照片分组背景、每 1–1000 次正式翻页在所选组内轮换、0–100% 深色遮罩；照片文字色可独立设置，自定义字体色与背景色分别保留历史。
- 深色、浅色、跟随系统；批量导入 TTF / OTF，持久化字体列表并随时切换；调整字号、行间距、字间距、段间距、颜色。
- macOS 标题栏磨砂、正文可完全透明、统一圆角、任意缩放与窗口尺寸恢复；在应用菜单“设置…”（⌘,）调整背景不透明度，0% 时阅读背景完全透明。
- 四位数字密码与固定数字键盘；PBKDF2 校验、错误次数限制；macOS 最小化保持解锁，重新启动或手动锁定时验证密码，Android 后台返回重新锁定。
- 文件面板使用 Android SAF 和 macOS NSOpenPanel，文件复制入应用存储后可持续离线读取。
- 横排与古书竖排可切换，竖排可选从右向左或从左向右的列序；标题、标点、西文与分页均适配，切换后保留进度。
- iOS 使用系统照片选择器，支持浅色、深色 App 图标（深色图标需 iOS 18+）；书籍和字体通过前台 Wi-Fi 上传页批量导入。iOS 最低版本 14，Wi-Fi 上传入口也可在 Android/macOS 设置中使用。

## 格式边界

当前阅读引擎按原书的文字与段落顺序统一重排，不保留 EPUB/MOBI 的插图、原书 CSS 和复杂版式。纯图片/扫描版、DRM 加密文件暂不支持。TXT 无 BOM 时优先 UTF-8，失败后使用 GBK。全文搜索最多显示前 300 处匹配。

电子书单文件限制 64 MB（字体不设固定大小上限）；EPUB 解压总量 128 MB；正文上限 1200 万 UTF-16 单元。长章节自动切成有界片段，避免整个长篇在窗口缩放时一次性排版。格式解析在可终止的隔离线程中执行。

密码锁控制应用访问；书籍和书架文件保存在系统应用目录，未对正文做文件加密。请牢记密码，界面没有跳过验证的重置入口。

## 构建与下载

GitHub Actions 的 `Build Reader` 在 main 推送和手动触发时运行：静态检查 → 格式/存储/分页/响应式/上传协议测试 → 所选平台构建。当前 main 推送默认构建 Android、未签名 iOS 和 macOS 三端；三端全部成功才更新 `preview`。手动运行仍可选择 macos-android、macos、android、ios 或 all，各平台组合分别发布。

[测试版下载](https://github.com/roy-xiong/reader/releases/tag/preview)

Android 当前使用测试签名，构建间签名可能变化。本机调试版使用独立的 `.debug` 包名。macOS 使用 ad-hoc 签名，未做 Apple 公证。iOS IPA 尚未签名，安装前需要用自己的 Apple 证书和描述文件签名；平台编译通过不等于已在 iPhone/iPad 真机验证。

## 照片、配色与 Wi-Fi 上传

设置中可一键应用纸白、羊皮纸、柔和灰、竹青、雾蓝、深海、墨色、午夜配色。配色参考 [Readwise Reader 的阅读主题](https://docs.readwise.io/reader/docs/faqs/appearance) 和 [Apple Books 的主题设置](https://support.apple.com/guide/iphone/read-books-iphc1af7c57/ios)，本应用独立定义文字与底色色值。

背景照片复制入应用存储，并缩至最长边 2048 以控制解码内存。图片组只保存照片引用，可共享成员；导入照片会加入当前组，删除组保留原照片。选中的图片组、循环位置以及照片文字色均持久化。成功的前后翻页累计轮换次数；目录、搜索和滑动进度预览不累计。选择纯色主题可切回纯色，已导入照片继续保留。

Wi-Fi 上传参考 [Documents 的电脑传输流程](https://support.readdle.com/documents/getting-started/add-files-to-documents)：

1. 本机与电脑连接同一 Wi-Fi，在阅读器打开“Wi-Fi 上传”并启动。
2. 在电脑浏览器打开 `http://设备IP:9900`，直接选择文件，无需传输码，地址不带类型参数。
3. 批量选择或拖入书籍、字体，网页会显示进度及每个文件的导入结果。
4. 字体上传后在设置的字体列表中选择。请保持传输页在前台，离开或切到后台后服务关闭。

传输网页不加载外部资源，文件直接写入本机仓库。服务仅在传输页前台运行，保留局域网地址、Host 和同源校验，采用文件流处理大字体；书籍仍限制 64 MB。

## 本地开发

```sh
flutter pub get
flutter analyze --no-pub
# 在需要时自行编译：
flutter run -d macos
flutter build apk --release
```

仓库不包含本机 SDK 路径、签名密钥、书籍文件或用户数据。平台包由 GitHub Actions 构建，测试截图也会作为流水线附件保存。

## 代码结构

- `lib/domain`：不可变模型和分页。
- `lib/data`：格式解析、文件/窗口通道、串行原子持久化与密码推导。
- `lib/ui`：应用模型、书架、阅读、设置与锁屏。
- `android`：Kotlin 系统选择器与后台文件复制。
- `macos`：Swift 透明窗口、原生菜单与沙盒文件面板。
- `ios`：Swift 场景入口、系统照片选择器；书籍和字体经共享 Flutter 局域网上传服务导入。

## 1.0.2 阅读体验

设置页可调整正文原文 / 简体 / 繁體，以及 100–900 字重。简繁转换使用内置 OpenCC 标准字词表，原书不被改写，进度和书签始终映射到原文。目录只显示实际章节，打开时定位当前章；章节标题放大并加分隔线。旧版书籍缓存首次打开自动更新，使用文字上下文迁移原定位。

阅读页支持 Esc 最小化、⌘+ / ⌘- 调整字号。显示的页码是当前窗口和排版参数下的全书页码；后台计数期间仍可阅读，连续调整窗口时取消过期计数。

应用显示名为“阅读”，内部标识和原有存储目录沿用 `com.xiongjian.reader` / `Reader`。平台构建额外执行窗口缩放几何回归测试。


竖排参考 [W3C 中文排版需求](https://www.w3.org/TR/clreq/) 的字向与列序，西文采用连续词顺时针侧排。显示层替换竖排标点，原书文本与搜索、书签坐标不变。当前为可重排纯文字竖排，不包含古籍影印、双行夹注和复杂表格。


## 坚果云同步（1.5.0）

设置 → 文件与同步 → 坚果云同步。WebDAV 默认地址 `https://dav.jianguoyun.com/dav/`。使用坚果云账号和第三方应用密码，首次创建专属目录并保存恢复码；其他设备用相同账号、目录和恢复码加入。凭据和密钥只保存在 Keychain / Android 安全存储；云端资源和元数据认证加密，无自建服务器。

阅读进度自动写入本机待传队列，前台联网后上传；连续快速翻页约 500ms 合并一次最新位置，服务限流时退避重试。打开书籍前按阅读更新时间检查云端，用户确认后才追到云端位置，百分比不参与判断。断网或检查耗时较长时可继续本机阅读。

书籍、字体、照片均主动上传和下载，照片同时携带图片组；上传书籍包含原始文件及解析缓存，保证相同版本的原文定位一致。字号、主题、透明度、颜色、密码等设置保持本机，不自动同步；书签随手动上传的书籍备份，不做自动合并。传输进度固定显示在同步页底部。资源加密分块为 2MiB，字体不新增人为大小限制。

`CloudStore` 隔离网盘协议，`CloudAssets` 管理分块与校验，`CloudSyncController` 管理手动传输和自动进度队列。每台设备写自己的 head / 进度，避免两个设备覆盖同一个 JSON；元数据保留未知字段，协议不兼容时停止读取。删除本地副本不会自动删除云端资料；当前没有远端删除入口。

验证包含本地 HTTP WebDAV 服务、两个独立仓库、加密篡改检测、较小但时间更新的进度、重启补传以及照片组／字体传输。尚未使用真实坚果云账号做端到端验证，服务配额和授权以实际账号为准。

## 1.6.0 设置与阅读外观

深色界面使用中性炭黑与灰阶容器、柔和暖灰强调色；正文默认 `#999999`。参考 [Kobo 的夜间阅读模式](https://help.kobo.com/hc/en-us/articles/360017708014-Adjust-screen-brightness-and-page-appearance-on-the-Kobo-Books-app-for-iOS) 和 [Apple Books 的主题与排版设置](https://support.apple.com/guide/iphone/read-books-iphc1af7c57/ios)，配色由本应用独立定义，已有自定义文字色与背景色继续保留。

设置首页只有分类入口。字体与排版、背景与颜色、翻页与操作使用同一个预览组件，统一呈现字体、字号、粗细、字距、行距、段距、横竖排、背景色、照片、遮罩和透明度，可直接试翻。手机在顶部固定预览、下方滚动选项，宽窗口左右分栏；键盘导致可用高度过小时暂时收起预览。试翻不改变书籍进度或照片循环位置。

正式阅读区域以系统安全区为边界，左右上下使用相同边距，进度信息位于底部留白内。取消大窗口的额外正文宽度限制；正文软换行两端对齐，段落末行和章节标题保持自然对齐，续页排版上下文不计入正文、语义或进度。

iOS 在“背景与颜色”新增“相册访问权限”，可主动申请完整照片权限，已选照片受限时可管理选择或前往系统设置。普通选图保留系统 PHPicker，不将完整授权作为前置条件；读取失败会显示数量和重试提示，并保留已成功导入的照片。权限最终由系统和用户选择决定。

## 1.7.0 本机上传与阅读快捷调节

本机资源记录新增按类型和内容标识持久化的来源。书籍、字体、照片从云端下载后，不会混入“上传本机资源”；文件面板和 Wi-Fi 导入的新资源仍可主动上传。旧版无来源记录的项目在刷新目录后迁移：相同内容已经存在于当前云端时按已同步项目跳过。记录为本机导入的照片仍可重复手动备份图片组更新。

点击正文中央后，底部工具栏包含进度、字号和亮度滑块。字号即时重新排版，保留阅读定位；双指纵向滑动可快捷调节亮度，手势期间不触发翻页。支持 Flutter 提供的触控板平移事件，鼠标滚轮翻页继续可用。

阅读亮度范围 10%–100%，仅调整阅读区域的颜色，不修改系统亮度，也不改变背景透明度。工具栏保持原亮度，书架和设置不受影响；偏好保存在本机，背景设置和统一预览也可调整和查看该效果。

Wi-Fi 上传使用固定 9900 端口，不带 `?kind=font` 等首页参数，也不再要求传输码。端口占用时显示明确错误，不改用随机端口；停止旧服务后可重新使用相同地址。离开传输页、锁定或进入后台会关闭服务。
