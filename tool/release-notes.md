阅读 1.7.1 · 整页覆盖与跟手翻页（Android / iOS / macOS）

- 横向覆盖翻页移动整张纸面，包括底色、照片背景与正文留白；旧页轻微缩小下沉，并在新页边缘显示柔和阴影。
- 覆盖、推移、纵向和层叠翻页支持跟手拖动。慢滑时实时预览，松手根据距离和速度完成翻页或平滑回弹，支持途中反向拖动。
- 手势预览与回弹不保存阅读进度、不累计照片轮换；正式翻页后才提交。跨章节复用相邻章节预排版，缓存最多两个相邻章节。
- 保留透明背景的透明度，不重复铺设纸色；手势开始时固定两页照片，避免提交时提前跳到下一张背景。
- 阅读页和设置中的统一预览共用交互，处理书首书尾、窗口缩放、锁屏、退出及双指调节亮度时的取消。

产物：Android APK、未签名 iOS IPA、macOS 通用 DMG / ZIP。iOS 需要自行签名；macOS 使用 ad-hoc 签名且未公证；Android 使用测试签名。
