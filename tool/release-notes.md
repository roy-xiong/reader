阅读 1.4.0 测试版。

- 新增古书竖排：每列从上至下，列序可选从右向左或从左向右；汉字正立、西文侧排、竖排标点及标题分隔线，保留原文进度、书签、搜索、全书页码和翻页预览。
- 背景照片可创建、命名、编辑多个图片组；同一照片可加入多组，按选中组的成员循环。删除组不删除照片，选中组及循环位置持久化。
- 照片背景可独立设置文字颜色，颜色保存到自定义字体颜色历史，不改变纯色背景的文字颜色。
- iOS 选择照片直接打开系统相册，多选后逐张降采样；新增浅色、深色两套 App 图标，由 iOS 主屏幕外观选择使用（深色图标需 iOS 18 或以上）。

- macOS 设置页新增明确的本地书籍、文件夹导入入口，书架“导入本地书籍”和系统“文件 → 导入电子书…”继续使用原生文件面板。
- Esc 改为 macOS 应用级最小化，书架、设置、Flutter 弹窗、Wi-Fi 上传和密码页均生效，最小化不关闭当前弹窗。
- 密码页支持主键盘和数字小键盘输入、退格、删除及回车；首次显示主动获取焦点，密码校验期间不重复提交。
- 粒子改为像素级细墨点，保留方向感开关；新增独立的“水墨消散”，文字在原位晕开并被柔边墨云溶解，背景保持静止。

- 支持多张照片作为阅读背景，设置每 1–1000 次正式翻页轮换；进度预览、目录和搜索跳转不计数。
- 照片深色遮罩可在 0–100% 调整；背景照片、轮换位置、次数和阅读设置持久化。
- 新增纸白、羊皮纸、柔和灰、竹青、雾蓝、深海、墨色、午夜八套官方阅读配色，一键设置文字和底色；单独设置过的颜色保留在自定义颜色历史。
- 新增 iOS 工程及 Wi-Fi 书籍、字体上传：同一 Wi-Fi 内通过电脑浏览器输入临时传输码、批量上传，离开页面或进入后台后停止传输。
- iOS 平台生成未签名 IPA 供后续签名；安装到 iPhone / iPad 需要使用自己的 Apple 签名，不是可直接安装的已签名包。

- 粒子效果默认取消翻页方向感：前后翻页都在原笔画周围均匀消散和聚合。
- 设置中新增“粒子方向感”开关，可恢复跟随翻页方向的飘散效果，选择会持久化，设置试翻同步生效。

- 翻页效果扩展为横向覆盖、横向推移、纵向翻页、纸张卷页、硬页翻转、卡片翻转、层叠翻页、淡入淡出、文字粒子消散和无动画。
- 粒子消散从实际文字笔画生成颗粒，在原位置散开并聚合到下一页；透明阅读背景保持不动。
- 设置页可以直接试翻效果，选择结果持久化。系统关闭动画时立即翻页；排版变化、退出页面时取消动画并释放临时墨迹图像。

- 新增单页翻页预览：拖动进度条浏览全书，松手保留预览，左右滑动或箭头逐页微调，点击预览正文或“阅读此页”才正式跳转。
- 预览显示真实章节、全书页码和百分比，关闭或返回不会修改阅读进度；缩略页沿用正文分页、字体、颜色和简繁设置。
- 本机 Android 调试包以“阅读（调试）”独立安装，保留已安装测试包及其书架。

- 修复 macOS 页面左右和底部未铺满窗口的问题：页面贴合窗口内容边缘，加宽的缩放热区通过覆盖层保留。

- macOS 仅标题栏磨砂；阅读背景 0% 时完全透明。窗口外沿提供更宽的缩放热区，重启恢复上次窗口大小和位置。
- 所有 macOS 页面 Esc 最小化，⌘+ / ⌘- 调整字号；进度显示全书页码，窗口和排版变化后重新计算。
- 缩小搜索图标，统一圆角下拉菜单；深色默认文字 #999999，颜色输入使用独立 # 前缀与六位色值。
- 新增正文原文 / 简体 / 繁體转换和字体加粗滑块，偏好持久化，进度和书签使用原文坐标保存。
- 修复 MOBI 按实际标题分章；旧书首次打开自动升级缓存并迁移进度和书签。目录定位当前章并高亮，正文标题放大并加分隔线。

macOS 下载通用 DMG，将“阅读.app”拖入 Applications；Android 下载 APK。

均为测试包，macOS 尚未使用 Apple 开发者证书公证。当前支持可重排文字，不保留原书插图和复杂版式。
