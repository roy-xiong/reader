Reader 1.0.1 本地电子书阅读器测试版。

- macOS：原生磨砂玻璃背景、统一圆角；应用菜单“设置…”（⌘,）调整阅读背景不透明度。
- 重绘应用图标和界面矢量图标，修复原图标装饰超出圆角轮廓的问题。
- 修复数字密码键盘最后一行被裁切；macOS 最小化恢复保持当前解锁状态。
- 字体导入取消固定大小限制，支持多选导入、持久化列表和随时切换；兼容旧版字体记录迁移。
- 书架卡片宽高约减半，面积约为原来的四分之一。

Android 下载 APK；macOS 下载通用 DMG 拖入 Applications，也可使用 ZIP。阅读页默认正文和进度，点击中央显示工具。

安装包使用测试签名，macOS 尚未使用 Apple 开发者证书公证。当前以可重排文字为主，不保留插图、原书 CSS 和复杂版式。
