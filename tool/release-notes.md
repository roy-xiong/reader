阅读 1.5.0 坚果云同步测试版（macOS + Android）。

- 设置新增“坚果云同步”：支持专属目录、首台设备建库、恢复码加入同一云书架；应用密码与恢复码仅进入设备安全存储，云端资料使用 AES-256-GCM 加密。
- 每次阅读位置变化写入待传队列，前台联网时尽快上传；快速连续翻页合并最新位置，断网后保留队列并重试。
- 打开同一本书前检查各设备的阅读更新时间；云端时间更晚且位置不同才提示“保持本机位置 / 追到云端进度”，不按百分比大小判断。
- 书籍、字体、照片由用户主动上传／按需下载；支持批量下载、照片组恢复和更新，传输时固定显示进度条、当前文件及完成数量。
- 字号、主题、颜色、密码等其他设置不自动同步；书签随手动书籍备份，未增加自动书签同步。
- 分块传输与完整文件校验；失败不会发布半个资源目录。协议保留未知业务数据，防止旧端擦除新字段。
- macOS 开启出站网络能力；安全存储使用无需描述文件的本机 Keychain；Android 避免系统自动备份复制设备绑定的安全凭据。
- 本轮只生成 Android APK 和 macOS 通用 DMG / ZIP，iOS 构建跳过。

首次测试：在坚果云生成“第三方应用密码”，首台设备选择“首次创建”并保存恢复码；另一台填写同一账号、目录和恢复码加入，刷新目录后下载书籍。先在 A 阅读，再在 B 打开同一本书检查进度提示。

已有功能继续包含横竖排、简繁转换、图片组、字体管理、全局 Esc、键盘密码以及粒子和水墨翻页。
macOS 测试包采用 ad-hoc 签名，尚未 Apple 公证；Android 为测试签名。尚未使用你的坚果云账号做实际服务联调。
