阅读 1.2.0 测试版。

- 翻页效果扩展为横向覆盖、横向推移、纵向翻页、纸张卷页、硬页翻转、卡片翻转、层叠翻页、淡入淡出、文字粒子消散和无动画。
- 粒子消散从实际文字笔画生成颗粒，在原位置散开并聚合到下一页；透明阅读背景保持不动。
- 设置页可以直接试翻效果，选择结果持久化。系统关闭动画时立即翻页；排版变化、退出页面时取消动画并释放临时墨迹图像。

- 新增单页翻页预览：拖动进度条浏览全书，松手保留预览，左右滑动或箭头逐页微调，点击预览正文或“阅读此页”才正式跳转。
- 预览显示真实章节、全书页码和百分比，关闭或返回不会修改阅读进度；缩略页沿用正文分页、字体、颜色和简繁设置。
- 本机 Android 调试包以“阅读（调试）”独立安装，保留已安装测试包及其书架。

- 修复 macOS 页面左右和底部未铺满窗口的问题：页面贴合窗口内容边缘，加宽的缩放热区通过覆盖层保留。

- macOS 仅标题栏磨砂；阅读背景 0% 时完全透明。窗口外沿提供更宽的缩放热区，重启恢复上次窗口大小和位置。
- 阅读页 Esc 最小化，⌘+ / ⌘- 调整字号；进度显示全书页码，窗口和排版变化后重新计算。
- 缩小搜索图标，统一圆角下拉菜单；深色默认文字 #999999，颜色输入使用独立 # 前缀与六位色值。
- 新增正文原文 / 简体 / 繁體转换和字体加粗滑块，偏好持久化，进度和书签使用原文坐标保存。
- 修复 MOBI 按实际标题分章；旧书首次打开自动升级缓存并迁移进度和书签。目录定位当前章并高亮，正文标题放大并加分隔线。

macOS 下载通用 DMG，将“阅读.app”拖入 Applications；Android 下载 APK。

均为测试包，macOS 尚未使用 Apple 开发者证书公证。当前支持可重排文字，不保留原书插图和复杂版式。
